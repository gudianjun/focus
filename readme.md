# 专注模式

一个在 Windows 电脑上启动专注倒计时的小工具。使用 .NET 10（C# / WPF）开发。

## 1. 窗口位置

- 设定窗口和倒计时窗口都显示在**屏幕正上方居中**的位置（水平居中，贴近顶部，留少量边距）。
- 不放在右上角，避免遮挡其他程序的关闭按钮。
- 位置固定，不可以拖动。
- 位置按**主显示器的工作区**计算（避开任务栏）。每次显示窗口时重新计算，以适应多显示器、分辨率变化和 DPI 缩放。

## 2. 设定画面

- 无标题栏、无工具栏的小窗口，显示在屏幕正上方居中。可以关闭，不可以移动。
- 时长下拉框：10、20、30、45、60 分钟，默认 30 分钟，最长 1 小时。
  - 也可以手动输入时长（1～60 分钟）。
  - 记住上次选择的时长，下次启动时默认选中。
- 任务名输入框（可选）：写一句"这次要做什么"。
- 一个"开始"按钮。
- 此时窗口是普通层级，可以被其他窗口遮挡。
- 关闭窗口后最小化到右下角的托盘图标，程序不退出。

## 3. 托盘图标

- 左键单击托盘图标：显示设定画面（专注中则显示倒计时窗口）。
- 右键菜单：
  - 显示
  - 开始 / 暂停（专注中时）
  - 设置
  - 退出（退出整个程序；专注中退出需要确认）
- 专注中，鼠标悬停在托盘图标上时显示剩余时间，例如"专注中 12:34"。

## 4. 倒计时画面

- 点击"开始"后进入倒计时，窗口变大，仍然显示在屏幕正上方居中的位置。
- 进入倒计时后，窗口**始终显示在所有窗口的最前面**。
- 为了不挡住工作区：
  - 开始几秒后自动缩成一个小计时条，鼠标移上去时展开；
  - 支持设置窗口透明度。
- 按钮：
  - **暂停 / 继续**：暂停期间窗口保持置顶，显示"已暂停"。
  - **放弃**：中止本次专注，回到设定画面。点击后弹出确认框，防止误操作。
- 倒计时结束时：
  - 播放提示音（可选择声音，或者关闭）；
  - 弹出 Windows 通知；
  - 询问"完成了吗？"（填了任务名时）；
  - 然后自动回到设定画面，窗口恢复普通层级。

## 5. 状态流转

```
[托盘] ⇄ [设定画面(普通层级)] --开始--> [专注中(置顶)] ⇄ [暂停(置顶)]
                ↑                              |
                └── 完成(提示音+通知) / 放弃(确认) ──┘
```

## 6. 设置项

- 开机自动启动（开关）
- 全局快捷键（默认 Ctrl+Alt+F：开始 / 暂停）
- 结束提示音（选择声音 / 关闭）
- 倒计时窗口透明度
- 是否自动缩成小计时条
- 设置保存在 `%AppData%\Focus\settings.json`

## 7. 功能规划

### 第一版（必须）

- 第 1～5 节的全部内容
- 自定义时长、记住上次的时长
- 只允许运行一个实例
- 开机自启、全局快捷键
- 设置持久化

### 第二版

- **番茄钟模式**：专注 25 分钟 → 休息 5 分钟，每 4 轮休息一次长休息（15 分钟）。休息结束时提醒"回来继续"。
- **统计**：今天、本周的专注次数和总时长，按任务名汇总。数据保存在本地（JSON 或 SQLite）。
- **白噪音**：专注期间可选的背景音（雨声、咖啡馆等）。

### 以后再考虑

- 专注期间开启 Windows"请勿打扰"（Windows 没有公开的稳定 API，可能只能引导用户打开系统设置）。
- 拦截分心的应用或网站。
- 严格模式：专注期间不允许放弃。

## 8. 技术方案

- **框架**：.NET 10 + WPF。
- **窗口**：`WindowStyle=None`、`ResizeMode=NoResize`、`ShowInTaskbar=False`。不调用 `DragMove`，并拦截 `WM_MOVING` / `WM_NCHITTEST`，防止被 Win+方向键等方式移动。
- **窗口位置**：用 `SystemParameters.WorkArea` 计算，`Left = (WorkArea.Width - Width) / 2 + WorkArea.Left`，`Top = WorkArea.Top + 边距`。
- **托盘图标**：在项目里加 `<UseWindowsForms>true</UseWindowsForms>` 后使用 `System.Windows.Forms.NotifyIcon`，或者使用 `H.NotifyIcon.Wpf` 包。
- **计时**：开始时记录 `结束时刻 = 现在 + 时长`，每次 Tick 用 `结束时刻 - 现在` 算剩余时间，避免累加误差和电脑睡眠后时间不准。暂停时保存剩余时间，继续时重新计算结束时刻。
- **置顶**：除了 `Topmost=true`，专注期间定时调用 `SetWindowPos(HWND_TOPMOST)` 重新置顶，防止被全屏程序或其他置顶窗口压到下面。
- **单实例**：使用命名 `Mutex`。再次启动时激活已运行的实例并显示窗口。
- **高 DPI**：在 `app.manifest` 中设置 `PerMonitorV2`。
- **通知**：使用托盘图标的 `ShowBalloonTip`，Windows 10/11 会显示为系统通知，不需要额外的包。
- **数据文件**：设置保存在 `%AppData%\Focus\settings.json`；每次专注（完成或放弃）追加一行到 `%AppData%\Focus\history.jsonl`，供第二版的统计功能使用。
- **开机自启**：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。
- **发布**：`dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true`，输出单个 exe。

## 9. 开发

### 目录结构

```
Focus.slnx
src/Focus/
  App.xaml(.cs)            启动、单实例、设置应用、退出
  MainWindow.xaml(.cs)     设定画面 / 倒计时画面 / 小计时条（同一个窗口）
  SettingsWindow.xaml(.cs) 设置对话框
  TrayIcon.cs              托盘图标和右键菜单
  AppSettings.cs           设置的读写
  SessionLog.cs            专注记录
  HotKey.cs                快捷键字符串解析
  AutoStart.cs             开机自启
  Sounds.cs                提示音
  NativeMethods.cs         Win32 API
```

### 编译和运行

```
dotnet build
dotnet run --project src/Focus
```

加 `--tray` 参数启动时只显示托盘图标（开机自启时使用）。
